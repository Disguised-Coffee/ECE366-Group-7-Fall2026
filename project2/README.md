# Project 2

THIS CALCULATES THE `n`th number in the fibonacci sequence, using the combinatorial definition from [https://stackoverflow.com/questions/1451170/in-the-fibonacci-sequence-is-fib0-0-or-1](https://stackoverflow.com/questions/1451170/in-the-fibonacci-sequence-is-fib0-0-or-1) and checks if it is odd. Currently, the entire program can be callable from `isFibonacci` with the input parameter as the number to find in the sequence and if it's odd.

## 🚀 How to Run

### prequistes:
- You have Java J2SE 1.5 (or later) SDK
- You can open file explorer and open a file with a program

### Steps

#### Setup
1. Download and setup the latest release of MARS from [https://dpetersanderson.github.io/index.html](https://dpetersanderson.github.io/index.html). 

2. If not prompted, open the file `Mars4_5.jar`

2. Open the project's `main.asm` file in the application with `Ctrl + O` or by navigating to `file > Open...`

#### Running

3. Assemble the program with `F3` (windows) or with `Run > Assemble`

4. Run the program with `F5` or with `Run > Go`. The results can be found in the `Run I/O` tab within MARS.

5. To change the number to calculate in the sequence and check as odd, adjust line 4 of `main.asm`, where n is currently referred to as 5. This value will be used in `main`.
