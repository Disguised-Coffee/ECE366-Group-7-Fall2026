## 🚀 How to Run

### prequistes:
- You have Java J2SE 1.5 (or later) SDK
- You can open file explorer and open a file with a program

### Steps
1. Download and setup the latest release of MARS from [https://dpetersanderson.github.io/index.html](https://dpetersanderson.github.io/index.html). 

2. If not prompted, open the file `Mars4_5.jar`

2. Open the project's `main.asm` file in the application with `Ctrl + O` or by navigating to `file > Open...`

3. Assemble the program with `F3` (windows) or with `Run > Assemble`

4. Run the program with `F5` or with `Run > Go`. The results can be found in the `Run I/O` tab.
